---
Using `TODO.md` (Session log + ticked tasks) and `git log --since="7 days ago" --oneline`, write `docs/weekly/week-$ARGUMENTS.md` with:

1. **What we built** (3–6 bullets, concrete).
2. **Why** (the key design decisions this week and the alternatives we rejected, in plain language).
3. **What I learned** (concepts, 2–4 bullets).
4. **Interview questions this week prepares me for**, each with a 2–3 sentence answer.
5. **CV bullets** (1–2, action verb + tech + measurable result where possible).
6. **Risks / open issues**.

Keep it under one page. Plain English.
