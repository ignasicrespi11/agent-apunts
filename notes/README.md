# notes/

Raw notes live here. Everything in this folder except this README is gitignored, so your notes never reach GitHub.

Layout (metadata is derived from the path + `config/sources.yaml`, never hardcoded):

```
notes/<university>/<degree>/<subject>/<doc_type>/<file>
e.g. notes/uab/computer-engineering/operating-systems/theory/tema3.pdf
```

`doc_type` examples: `theory`, `labs`, `exercises`, `exams`, `personal`.
