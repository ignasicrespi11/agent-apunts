# apunts/

Inbox for your real course material. Drop PDFs here, organised or not.
Everything in this folder except this README is gitignored, so it never reaches GitHub.

- Optional hint: `apunts/<subject>/<doc_type>/<file>.pdf`. If present, the folder name wins over auto-detection (D18).
- Without folders, metadata is auto-detected from the title slides and filename (from week 4).
- `doc_type`: `theory`, `labs`, `exercises`, `exams`.
